# 모듈 F. 병원 / 뷰티 / 의료 관련

## 핵심 불안
안전성, 의료진 신뢰, 비용

## 섹션 순서
히어로 → 진료/시술 소개 → 의료진 → 장비/시설 → 진료 과정 → 비용 안내 방식 → 오시는 길 → 예약 CTA

## 법적 주의 (반드시 먼저 확인)
- 치료 경험담, 전후사진, 효과를 단정하는 표현은 의료 광고 규제 대상이다.
- 해당 섹션은 **법적 검토 필요**로 표시하고, 대체안을 우선 제안한다.
- 과장 표현(최고, 100%, 완치 등)은 쓰지 않는다.

## 대체안 (후기·전후사진 대신)
- 의료진 이력과 자격
- 인증 및 시설 정보
- 장비 소개
- 진료 과정 설명 (상담 → 진료 → 사후 안내)
- 비용 안내 방식 (상담 후 확정 등, 실제 방식대로)

## CTA
- "예약 문의하기"
- "전화로 상담하기"

## 주의
- 의료 관련 문구는 최종 게시 전 전문가 검토를 권한다.
