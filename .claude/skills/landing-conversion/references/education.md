# 모듈 E. 교육 / 강의 / 코칭

## 핵심 불안
효과가 있나, 나에게 맞나, 환불되나

## 섹션 순서
히어로(수강 후 결과) → 문제 공감 → 강사 권위 → 커리큘럼 → 수강생 성과/후기 → 대상 체크리스트(맞는 사람/안 맞는 사람) → 가격+환불 규정 → FAQ → 마감 CTA

## 필수 요소
- 수강생 전후 성과 (동의받은 것만)
- 환불 규정 (실제 약관과 일치)
- 마감 긴박감: 실제 모집 기한이 있을 때만

## 주의
- "안 맞는 사람" 체크리스트를 넣으면 신뢰가 올라간다. 과장보다 정직한 기준이 전환을 돕는다.
- 가짜 마감 카운트다운은 쓰지 않는다.
