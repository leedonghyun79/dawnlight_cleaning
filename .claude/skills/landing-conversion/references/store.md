# 모듈 G. 오프라인 매장 / 음식점 / 공간 대여

## 핵심 불안
위치, 분위기, 가격, 예약 가능 여부

## 섹션 순서
히어로(공간/메뉴 사진) → 대표 메뉴·공간 → 분위기 갤러리 → 리뷰(네이버/카카오 평점) → 이용 안내(가격, 시간) → 오시는 길 → 예약 CTA

## 필수 요소
- 네이버 지도 또는 카카오맵 연동
- 영업시간
- 주차 정보
- 예약 연동 (네이버 예약 등, 실제 사용 시)

## CTA
- "지도 보고 찾아가기"
- "예약하기"
- "전화 문의"

## 주의
- 영업시간과 주차 정보는 방문자가 가장 많이 확인하는 정보다. 틀리면 신뢰가 바로 떨어진다.
