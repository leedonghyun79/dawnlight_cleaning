# 모듈 B. SaaS / 앱

## 핵심 불안
써볼 가치가 있나, 배우기 어렵나, 해지 가능한가

## 섹션 순서
히어로(제품 화면) → 문제 공감 → 핵심 기능 3개(혜택으로 번역) → 사용 흐름/데모 → 고객사 로고+성과 수치 → 가격표 → FAQ → 최종 CTA

## 필수 요소
- 실제 제품 화면 (목업 아님)
- 무료 체험 여부
- 가격 공개
- "카드 불필요 · 언제든 해지" 같은 마이크로카피 (실제 정책일 때만)

## 생략 가능
전화 상담, 모바일 고정 버튼, 프로세스

## CTA
- "무료로 시작하기"
- "14일 무료체험"

## 주의
- 체험 기간, 해지 정책은 실제 서비스 설정과 일치해야 한다.
- 고객사 로고는 사용 허락을 받은 것만 쓴다.
