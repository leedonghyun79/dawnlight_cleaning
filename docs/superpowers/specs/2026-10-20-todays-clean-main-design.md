# 오늘의 청소 | 메인 페이지 설계 스펙

**최종 검토**: 2026-10-20
**프로젝트**: 청소업체 소개 웹사이트 - 메인 페이지
**스택**: Next.js 15 + TypeScript + Tailwind CSS + GSAP

---

## 1. 개요

"어떤 공간이든, 끝은 같은 기준으로" - 18평부터 800평까지 다양한 청소 서비스를 제공하는 청소업체의 소개 페이지.

**핵심 목표**:
- 공간별 청소 범위를 명확히 보여주기
- 18평~800평까지 작업 경험 증명 (규모 신뢰성)
- 사후 책임(A/S)까지 강조하는 CTA 플로우
- 모바일 유저가 손쉽게 견적 요청·전화 상담 가능

## 3. 각 섹션 상세 설계

### 3.1 Header
**용도**: 고정 상단 네비게이션
**높이**: 64px
**색상**: 흰색 배경 + 네이비 텍스트 + 흰색 테두리

**구성**:
- **좌측**: 로고 (16px 텍스트 또는 이미지)
- **중앙**: 메뉴 (About / Service / Portfolio / Review / FAQ / Contact)
- **우측**: CTA 버튼 (네이비 배경, 흰색 텍스트) - "무료 견적"

**인터렉션**:
- Scroll down → Header 배경 반투명 (shadow 추가)
- 메뉴 호버 → 텍스트 색상 변경 (네이비 → 강조색)
- 모바일 (768px 이하) → 햄버거 메뉴로 변경

### 3.2 Hero Section
**배경**: 아침 햇빛의 밝은 사무실 라운지 영상 (8초, 자동재생 음소거, 루프)
**높이**: 100vh (최소 600px)
**레이아웃**: 중앙 정렬 + 반투명 오버레이 (30%)

**텍스트**:
```
어떤 공간이든, 끝은 같은 기준으로

18평 오피스텔부터 800평 신축 오피스까지.
상담부터 사후 관리까지 5단계로 진행합니다.
```

**버튼** (2개, 수평 배치):
1. [무료 견적 문의] - 모달 또는 /contact로 링크
2. [010-1234-5678 전화 상담] - tel: 링크

**애니메이션**:
- Fade-in (영상 로드 후 타이틀 & 버튼 0.8초)
- 버튼 호버 시 스케일 1.05 + 그림자 강조

### 3.3 Service Section
**제목**: "맡기실 공간을 골라주세요"
**배경**: 흰색
**카드 배치**: 2열 그리드 (4개)

**카드 구조**:
```
┌──────────────────┐
│  현장 사진 (16:9) │
├──────────────────┤
│  서비스명        │  (H3)
│  한 줄 설명      │  (Body, 회색)

│  • 항목2         │
│  • 항목3         │
└──────────────────┘
```

**4가지 서비스**:
1. **입주·이사 청소** - "새 출발 전에, 실내 전체 먼지와 오염부터 비웁니다."
   - 창틀·몰딩·벽면 / 주방·욕실 집중 청소 / 세탁공간·현관

2. **거주 공간 청소** - "살고 있는 그대로, 구석 미세먼지까지 소독합니다."
   - 거실·방·주방·욕실 / 먼지 제거 및 소독 / 창틀·베란다

3. **사무실·상업 공간 청소** - "영업과 업무에 방해 없이, 마감 후 정리합니다."
   - 바닥·유리 / 책상·진열대·집기 / 화장실·탕비실 위생

4. **건축·준공 청소** - "공사가 끝난 자리에서 분진과 페인트 자국을 지웁니다."
   - 미세먼지·분진 제거 / 시멘트·페인트 자국 / 창호·유리

**정기 관리 배너** (카드 아래):
- 배경: 연한 하늘색
- 텍스트: "사무실, 매장, 학원은 주간·월간 정기 방문으로 맡기세요. 공간에 맞춘 스케줄과 위생 점검이 함께 갑니다."

**인터렉션**:
- 카드 호버 시 그림자 강조 + 스케일 1.02
- Scroll 트리거 fade-in (각 카드 약간씩 지연)

## 8. 애니메이션 & 인터렉션

### 8.1 GSAP 애니메이션
- **Scroll Trigger**: 섹션 진입 시 fade-in (duration: 0.6s)
- **Stagger**: 카드/항목 순차 페이드 (stagger: 0.1s)
- **Counter**: 통계 숫자 카운트업 (0 → 최종값, 1.5s)
- **Draw**: 타임라인 선 그려지기

### 8.2 전환 (Transitions)
- 모든 색상 변경: 200ms ease-in-out
- 버튼 호버: 150ms ease-out
- 아코디언 열림/닫힘: 300ms ease-in-out

### 8.3 호버 상태
- **버튼**: 배경색 0.15 어두워짐, 스케일 1.02
- **카드**: 그림자 강조, 스케일 1.02
- **링크**: 색상 변경 (네이비 → 강조색)

### 8.4 비디오 (Hero)
- 소스: `/public/videos/hero.mp4` (또는 WebM)
- 재생: 자동, 음소거, 루프
- 해상도: 1920x1080 (16:9)
- 파일 크기: ≤ 10MB (로드 성능)

## 9. 접근성 (Accessibility)

### 9.1 ARIA Labels
- 버튼에 `aria-label` 추가
- 아코디언에 `aria-expanded` 상태 관리
- 이미지에 `alt` 텍스트 포함

### 9.2 키보드 네비게이션
- Tab 키로 모든 상호작용 요소 접근 가능
- Enter/Space로 버튼·아코디언 활성화
- Esc로 모달 닫기

### 9.3 색상 대비
- 텍스트 vs 배경: WCAG AA 기준 (4.5:1 이상)
