# 모듈 A. 지역 서비스업 (청소, 인테리어, 이사, 방역, 수리)

## 핵심 불안
추가 요금, 파손, 결과 불만족, 업체 신뢰

## 섹션 순서
히어로 → 문제 공감 → 서비스(가격대/소요시간) → 비포애프터 → 후기+누적 건수 → 중간 CTA → 보증(재작업, 배상보험, 정직한 견적) → 프로세스 → FAQ → 최종 CTA

## 필수 요소
- 비포애프터 갤러리
- 지역+평수가 들어간 후기 (이니셜 포함, 동의받은 것만)
- 보증 섹션
- 전화/카톡 즉시 연락
- 모바일 하단 고정 버튼
- 사업자등록번호 (푸터)

## CTA
- "무료 견적 받기"
- "카톡으로 바로 상담"

## 주의
- 가격은 "공간 상태에 따라 상담 시 안내"처럼 사실대로 쓴다. 최저가·정액가를 임의로 만들지 않는다.
- 보증 문구(재청소, 배상보험, 추가 요금 없음)는 실제 약관 확인 후에만 노출한다.
